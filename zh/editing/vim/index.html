    Vim 模式¶

    Zume Editor 为文本标签页提供可选的 Vim 风格模式化编辑模式。它 默认关闭，且无需任何插件。

    开启¶

    • Edit → Toggle Vim Mode，或在 Vim 模式开启后输入 :set vim（用 :set novim 关闭）。
    • 该设置会被记住，并应用于每一个文本标签页。
    • Vim 模式仅对文本标签页生效。十六进制、大文件和 Git 标签页会忽略它。

    状态栏会显示当前模式：-- NORMAL --、-- INSERT --、 -- VISUAL --、-- V-LINE -- 或 -- V-BLOCK --。

    Ctrl 快捷键仍然有效

    常用快捷键（Ctrl+S 保存、Ctrl+F 查找、Ctrl+Shift+P 命令面板……）在每种模式下都照常有效。有两个 NORMAL 模式下的按键改为遵循 Vim 的约定：Ctrl+R 是重做，Ctrl+V 进入可视块模式。

    模式¶

    按键 模式
    i a I A o O INSERT（输入文本；Esc 返回 NORMAL）
    v VISUAL（字符方式）
    V VISUAL LINE
    Ctrl+V VISUAL BLOCK
    : / ? 命令行（ex / 搜索）

    移动¶

    h j k l（以及方向键）、w b e、0 ^ $、gg G、 {count}G（跳转到某行），以及 f t F T 跳到某个字符，配合 ; / , 重复。计数也有效：3j、42G、2w。

    操作符与文本对象¶

    • 操作符：d（删除）、c（更改）、y（复制）、> / <（缩进 / 反缩进）、gu / gU（转小写 / 大写）。
    • 将操作符与移动组合（dw、c$、y3j），或将其重复一次以作用于整行 （dd、yy、cc、>>）。
    • 文本对象：iw / aw，以及 i / a 配合 " ' ` ( { [ < —— 例如 ci" 更改引号内的内容，da( 删除圆括号及其内容。

    操作¶

    x D C p P J ~ r{char}，撤销 u / 重做 Ctrl+R，以及 . 重复上一次更改。命名寄存器以 "x 开头（例如先 "ayy 再 "ap）；无名寄存器 支撑着普通的 y / d / p。

    搜索与替换¶

    • /pattern 和 ?pattern 向前 / 向后搜索；n / N 重复，* / # 搜索光标下的单词。命令行会显示在状态栏中。
    • :[range]s/pattern/replacement/[g][i] 进行替换（:%s/…/…/g 作用于整篇文件， :s/…/…/ 作用于当前行）；:noh 清除匹配高亮。

    Ex 命令¶

    :w [name] 保存，:q 关闭标签页（:q! 放弃，:wq / :x 保存并 关闭），:qa / :wqa 作用于所有标签页，:{number} 跳转到某行，以及 :set vim / :set novim。

    Note

    Vim 模式与多光标 / 列模式不会同时使用。
