    发行说明¶

    当前版本显示在应用中（Help → About）。这是一个免费的公开测试版——所有 功能在 2027-03-31 之前均可免费使用。

    下载请见安装页面。请在 GitHub 上报告 缺陷和需求。

    0.30.0 — 首个公开测试版¶

    Zume Editor 面向 Windows、macOS 和 Linux 的首个公开测试版。

    亮点

    • 超大文件——打开、搜索、编辑和保存 10 GB 以上的文件，首屏几乎即时 呈现，而无需将其加载到内存中。
    • 十六进制编辑器——偏移量 / ASCII / EBCDIC 列、字节查找与替换、 模板、补丁（IPS / BPS / UPS / bsdiff / VCDIFF）。
    • Git 客户端——暂存 / 提交、分支、日志图、差异、冲突 解决、抓取 / 拉取 / 推送、工作树和 LFS。
    • 可停靠面板中的终端与 SSH shell，以及通过 SFTP / FTP / FTPS 进行的 远程编辑。
    • 数据库工具、双窗格差异与合并，以及 CSV 网格编辑。
    • Markdown / HTML 实时预览、格式与编码转换、一个 CLI （zume-cli），以及面向 AI 代理的 MCP 服务器。
    • 地理数据转换（MAP）：DMS、geohash、地图瓦片、GeoJSON / WKT / KML / GPX，以及日本平面直角坐标系。
    • 日常编辑：语法高亮、代码折叠、大纲、多光标、 列（块）模式、搜索与替换、分屏视图、宏、Lua 脚本和 会话恢复。

    一个许可证（针对即将发布的稳定版）涵盖全部三个平台。

    测试版更新 — 2026 年 10 月¶

    • 面向 AI 代理的 MCP，大幅扩展——zume-mcp 服务器现在将编辑器的大多数 引擎作为工具暴露：跨文件搜索与替换、地图数据转换（geo）、转换工具箱、 zip/tar 归档、二进制补丁、Markdown→HTML、大纲/符号列表、文件夹比较、流式 大文件搜索、Redis/MongoDB、只读 Git、云存储、沙盒化的 Lua 脚本， 以及安全分析（熵值、CyberChef 风格的转换配方、一个 YARA 规则子集扫描器）。 一个新的沙盒（ZUME_MCP_ROOTS / ZUME_MCP_READONLY）限定了代理可以读取 或更改的范围。参见 MCP。
    • Markdown 预览表格——GFM 竖线表格现在渲染为带边框的网格， 单元格内支持粗体 / 斜体 / 代码 / 链接，并支持按列对齐。 HTML 表格在所有平台上都能在预览中渲染。
    • 处理中光标——在超大文件正在打开时，以及文件内搜索或替换正在运行时， 会显示一个忙碌光标。
    • 对话框优化——过长的对话框标题不再换行或与关闭按钮重叠，Theme 对话框的 X 按钮和标题悬停已修复，Settings 对话框的滚动条会显示抓取光标。
    • 稳定性——修复了使用终端 / SSH 面板后可能发生的一处崩溃。
    • 各平台上的若干较小修复。

    测试版更新 — 2026-10-15（刷新版构建）¶

    Windows、macOS 和 Linux 的安装包从同一代码树重新构建；版本仍为 0.30.0。请从 安装页面重新下载以获取它们。

    • 转换配方对话框会列出每个步骤——Code → Apply Convert Recipe… 现在会在其字段下方显示完整的步骤列表：带键名的原语 （xor: / rc4: / rot:）、无参数的原语、短名称，以及按组归类的每个 转换器 id，因此无需记忆任何内容。文档所用的短名称（from_base64、 to_base64、from_base32、to_base32、gunzip、gzip、url_decode、 url_encode）现在已被接受——此前，引擎会将它们作为未知步骤拒绝。参见 转换配方。
    • 编辑器中的 YARA 扫描——Code → YARA Scan… 接受一个规则文件，扫描 活动文档，并在结果面板中列出每个匹配；点击某一行可跳转到其所在行。该配方 还新增了此前仅限 MCP 的转换原语（xor、rot、rc4、base58 / base85、 十六进制）。
    • 预览中的删除线——~~text~~ 以及 <del> / <s> / <strike> 现在会在 Markdown / HTML 预览中渲染为删除线 （Windows 和 Linux；macOS 目前将它们绘制为纯文本）。
    • macOS——使用上述修复及最新的 macOS 端优化重新构建了镜像。

    测试版更新 — 2026-10-21（刷新版构建）¶

    从同一代码树重新构建（仍为 0.30.0），包含一个大型逆向工程批次和浮动面板。请从 安装页面重新下载以获取它们。

    • 逆向工程——一套新的 Code 菜单工具可结构化地读取可执行文件，且绝不 运行它们：Executable Info（PE / ELF / Mach-O—— 头部、带熵值的节区、导入 / 导出、资源、加固措施）， Disassemble Executable（Capstone：x86 / 64、ARM、Thumb、AArch64）、 Cross-References 和函数恢复，以及可选的反编译器——它们会调用你安装的 工具——Ghidra、ILSpy（.NET）和 javap + CFR （Java）。新的 Objective-C / Swift Interface 恢复功能会读取 Mach-O 的 运行时元数据（类、方法、实例变量、属性、Swift 类型和去混淆后的符号）——在 macOS / iOS 二进制文件上最为有用。MCP 服务器暴露了相同的引擎（pe_info、 elf_info、macho_info、disassemble、 xrefs、functions、decompile）。参见 安全分析。
    • 浮动面板——任何停靠面板（终端、结果、FTP / SFTP / SSH、 比较）都可以浮动到它自己的窗口中——例如把一个终端放到第二台显示器上——然后 重新停靠，其实时内容仍会持续更新。 右键单击一个面板的标签页可获得 Float Tab 和 Move to Right / Bottom。 参见 快速入门。
    • macOS——逆向工程工具套件和浮动面板已在 macOS 构建上验证； 使用最新的 Mac 端优化重新构建了镜像。
    • 各平台上的若干较小修复。

    测试版更新 — 2026-10-22（刷新版构建）¶

    从同一代码树重新构建（仍为 0.30.0）。请从安装 页面重新下载以获取它们。

    • 设置路径修复（Windows）——包含反斜杠的文件系统路径—— Ghidra 和 ILSpy 的安装文件夹、ILSpy 缓存和恢复 目录——在 settings.json 重新加载时会被损坏（例如 C:\root\ghidra 变成了 C:rootghidra），这会导致 Code → Decompile 失败 并报 “analyzeHeadless not found”。现在设置路径可以正确地往返保存，并且 更新后能正确读取现有的 settings.json，无需重新输入这些路径。
    • 文件夹面板滚动修复——在文件夹面板已滚动到底部之后， 缩小结果面板会使该面板变大，并使其行滚动到顶部之外、滚动条消失、 无法返回。现在滚动偏移量会被限制，因此行永远不会被搁浅。
    • 所有平台都从同一次提交重新构建。

    测试版更新 — 2026-10-28（刷新版构建）¶

    从同一代码树重新构建（仍为 0.30.0）。请从安装 页面重新下载以获取它们。Microsoft Store（.msix）版本现在为版本 0.30.14.0。

    • 软制表符——Tab 键可以插入可配置数量的空格 而非一个制表符字符（Format → Tab Inserts Spaces…）；Tab / Shift+Tab 会按相同的宽度缩进整行。
    • 列表面板中的输入即过滤——在某个列表面板获得焦点时（Extract Strings、函数 / 符号大纲、最近文件、主题，…），输入 会将行缩小到不区分大小写的子串匹配；Backspace 编辑过滤条件， Esc 清除它。
    • 全角空格（U+3000） 现在会在空白字符可视化中显示，绘制为 一个独特的方框，以免被误认为 ASCII 空格。
    • 显式的转换配方键名——在 Code → Apply Convert Recipe… 中，一个 只是看起来像十六进制的 xor: / rc4: 键名会在状态栏中被标记出来， 而 hex: / str: 可强制指定解释方式。一个新的 Code → Toggle Strict Transform Keys 会直接拒绝裸键名。transform MCP 工具新增了 一个相应的 warnings 列表和一个 strict 选项。
    • 终端粘贴修复——Ctrl+V 现在会粘贴到正在运行的 shell 中，而不是 丢失。
    • 所有平台都从同一次提交重新构建。

    测试版更新 — 2026-10-29（刷新版构建）¶

    从同一代码树重新构建（仍为 0.30.0）。请从安装 页面重新下载以获取它们。Microsoft Store（.msix）版本现在为版本 0.30.15.0。

    • 严格转换键名移至设置——转换配方键名的严格模式开关现在位于 Tools → Settings… 中的 Transform recipe keys 下，不再位于 Code 菜单中，并且切换时不再打印状态栏 提示（对话框中的对勾即为状态）。行为保持不变——在严格模式下会拒绝 裸 xor:/rc4: 键名，否则会自动检测。参见 安全分析。
    • macOS 空白字符标记——macOS 编辑器现在会像 Windows 和 Linux 那样绘制 空白字符标记（空格圆点、制表符箭头、行尾段落标记和全角空格方框）； 此前 macOS 不显示任何标记。
    • 所有平台都从同一次提交重新构建。

    测试版更新 — 2026-10-29（刷新版构建，0.30.16.0）¶

    从同一代码树重新构建（仍为 0.30.0）。请从安装 页面重新下载以获取它们。Microsoft Store（.msix）版本现在为版本 0.30.16.0。

    • 代码菜单中的安全学习层——一组用于研究可执行文件的工具。
    • 可自我解释的 Executable Info——在 Tools → Settings… 中开启解说 （"Show what this means notes in the Executable Info report"），PE / ELF / Mach-O 的每个节标志、加固位（ASLR / DEP / CFG、PIE / NX / RELRO / 栈保护）、 熵值以及入口 / 导入 / 导出 / overlay 行下方都会给出一句通俗说明。
    • 控制流图——Code → Control-Flow Graph… 将一个函数（入口点）分解为 其基本块并显示它们之间的分支。
    • 熵图——Code → Entropy Map… 列出文件的整体熵、块的迷你折线图和 逐窗口序列，使加壳或高熵区域一目了然。
    • 捆绑的 MCP 服务器新增了一个相应的 cfg 工具。
    • 所有平台都从同一次提交重新构建。

    测试版更新 — 2026-11-04（刷新版构建）¶

    从同一代码树重新构建（仍为 0.30.0）。请从安装 页面重新下载以获取它们。Microsoft Store（.msix）版本现在为版本 0.30.18.0。

    • 可选的安全分析器集成——Tools → Run Security Analyzer… 会运行你配置的 外部、授权范围的分析器——例如配套工具 sanctum，一个单独的可选下载（编辑器 内不附带任何攻击性内容）——并在面板中按严重程度分组、带彩色徽章地列出其发现。 它可以分析当前标签页中的文件（校验被分析文件的哈希）或你选择的目标。分析器在 Tools → Settings… 中以 name = command 行配置。
    • 设置中的路径 / 分析器输入框可编辑——路径设置（Ghidra / ILSpy 安装文件夹 和 ILSpy 缓存）以及各分析器条目现在是单行文本框；较长的值会横向滚动而不再 换行被截断，Clear 按钮在清除某个值前会要求确认。
    • 捆绑的 MCP 服务器新增了一个相应的 analyze_run 工具。
    • 所有平台都从同一次提交重新构建。

    测试版更新 — 2026-11-13（刷新版构建）¶

    从同一代码树重新构建（仍为 0.30.0）。请从安装 页面重新下载以获取它们。Microsoft Store（.msix）版本现在为版本 0.30.21.0。

    • 简体中文——整个界面现已提供简体中文，可在 Tools → Settings… 的 Language 下选择，帮助链接也会将中文用户引导至中文帮助站点。
    • 便携模式——在 zume-editor.exe（便携 ZIP）旁创建一个名为 portable.txt 的空文件，设置、会话、恢复检查点、最近文件、known hosts、日志和许可证就会 保存到可执行文件旁边的 data 文件夹中，编辑器即可完全从 U 盘运行；删除该标记 文件即可恢复为按电脑保存。参见安装。
    • 所有平台都从同一次提交重新构建。

    测试版更新 — 2026-11-14（刷新版构建）¶

    从同一代码树重新构建（仍为 0.30.0）。请从安装 页面重新下载以获取它们。Microsoft Store（.msix）版本现在为版本 0.30.22.0。

    • 终端键盘修复——当编辑器区域中打开了比较 / diff 视图时，终端面板（以及 SSH / 结果面板）无法获得键盘：点击面板虽然能使其获得焦点，但按键仍被比较 视图吞掉，因此无法把光标移入终端或输入。现在面板一旦获得焦点即可接收输入和 光标移动，点击回编辑器则把键盘交还给比较视图。
    • 所有平台都从同一次提交重新构建。

    稳定版（1.0）发布时计划推出订阅方案。你的反馈将塑造 1.0——感谢你测试这个测试版。
