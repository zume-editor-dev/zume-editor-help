# MCP (AI Integration)

Zume Editor can act as an **MCP (Model Context Protocol) server**, letting a
compatible AI client read and edit through the editor's commands.

- Enable the MCP server in settings.
- Point your MCP-capable client at Zume Editor.
- The AI works through the same document and command pipeline you use, so edits are
  undoable and safe.

!!! info
    MCP is an open protocol for connecting AI assistants to tools and data sources.
