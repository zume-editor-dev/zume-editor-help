# MAP（地理数据转换）

无需离开编辑器即可转换和测量地理空间数据
（**工具 → 地理**）。

## 格式转换

在 **GeoJSON、WKT、KML、GPX 和 CSV**（点数据）之间进行转换。内部使用一个
中立模型，因此任意格式都可转换为其他任意格式。

## 坐标与变换

- **DMS &harr; 十进制**度数，以及 **geohash** 编码 / 解码。
- **Slippy-map 瓦片**（z/x/y、Bing quadkey、边界框）。
- **日本平面直角坐标系**（平面直角座標系，JGD2011，第 1-19 带）&harr; 经纬度。

## 测量

- GeoJSON / WKT 几何图形的大地**长度**和**面积**。

以上所有功能也可从命令行使用——参见
[CLI → geo](cli.md)。
