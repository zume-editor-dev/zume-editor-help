# 搜索与替换

## 查找栏

- ++ctrl+f++ 打开查找栏。++f3++ / ++shift+f3++ 跳转到下一个 / 上一个
  匹配项；++enter++ 为下一个。
- 使用 ++alt+c++（大小写）、++alt+r++（正则表达式）和
  ++alt+w++（全词匹配）切换选项。

## 查找与替换对话框

- ++ctrl+r++ 打开完整对话框，其中包含**查找**、**替换**、
  **在文件中查找**和**在文件中替换**等标签页。
- 多行搜索/替换字段（++ctrl+enter++ 插入换行符）、替换中的捕获
  组（`$1`..`$9`），以及搜索历史（++up++ / ++down++）。

## 范围

- 搜索**当前文件**、**选中的文本**，或**所有打开的文件**。
- 在启用列/块选择时，搜索会被限制在这些列范围内。

## 在文件中查找 / 在文件中替换

- 使用文件名过滤器（例如 `*.cpp, *.md`）以及包含/排除列表
  递归搜索某个文件夹。
- **在文件中替换**会在应用前显示每一处更改的**预览**，
  并且应用步骤是事务性的（写入失败会将所有更改回滚）。
