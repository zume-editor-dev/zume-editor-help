# 多光标与列模式

## 多光标

- **Alt+点击**可添加一个光标；++ctrl+alt+up++ / ++ctrl+alt+down++ 向上 / 向下
  堆叠光标。++esc++ 会折叠回单个光标。
- 输入、Backspace/Delete 和移动会作用于每个光标；重叠的
  光标会合并。多光标编辑算作单个撤销步骤。

## 列 / 块模式

- **Shift+Alt+拖动**可选择一个矩形区域。输入或删除会按行进行。
- **切换列模式**（++alt+shift+c++）可使 Shift+移动键构建一个块；在
  此模式下，普通拖动也会构建一个矩形区域。

## 列工具

- **列填充**——在块的每一行上插入相同的文本。
- **列编号**——插入一个递增的数字（`start[,step]`），以零填充。
- **在光标处对齐** / **按分隔符对齐**——对齐各列。
