# マルチカーソル & カラムモード

## 複数カーソル

- **Alt+クリック** でカーソル追加。++ctrl+alt+up++ / ++ctrl+alt+down++ で上 / 下へ
  積み増し。++esc++ で1つに戻ります。
- 入力・Backspace/Delete・移動は全カーソルに作用し、重なったカーソルは統合されます。
  マルチカーソル編集は1回の取り消しで戻せます。

## カラム（矩形）モード

- **Shift+Alt+ドラッグ** で矩形選択。入力・削除は行ごとに作用します。
- **Toggle Column Mode**（++alt+shift+c++）で、Shift+移動により矩形を作成。この
  モードでは通常のドラッグでも矩形になります。

## カラム用ツール

- **Column Fill** - 矩形の各行に同じテキストを挿入。
- **Column Number** - 連番を挿入（`開始[,増分]`、ゼロ埋め）。
- **Align at Carets** / **Align on Delimiter** - 列を揃えます。
