# 大容量ファイル

Zume Editor は、ファイル全体をメモリに読み込まずに **10&nbsp;GB 超** の巨大ファイルを
開けます。

- **瞬時に開く** - 表示部分だけを読み込み、巨大ファイルでも最初の画面が約1秒で表示。
- **その場で編集** - 局所的な編集でファイル全体を書き直しません。保存はストリーミング
  かつ堅牢（durable）です。
- **ストリーミング検索** - リテラル / 正規表現検索を、UIを止めずにファイル全体へ。
  末尾から先頭へ折り返します。
- **実際の行番号** - バックグラウンドの索引で、巨大ファイルでも正しい行番号と行/列を
  表示します。
- **大容量のHex** - [Hexエディター](../hex.md) も大容量ファイルで動作します。

ファイル全体をメモリに必要とする機能（シンタックスハイライト、Gitのガター差分、
折りたたみ）は、超大容量ファイルでは仕様上オフになります。
