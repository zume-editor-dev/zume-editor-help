# 検索と置換

## 検索バー

- ++ctrl+f++ で検索バー。++f3++ / ++shift+f3++ で次 / 前の一致、++enter++ で次へ。
- オプション切替：++alt+c++（大文字小文字）、++alt+r++（正規表現）、
  ++alt+w++（単語単位）。

## 検索と置換ダイアログ

- ++ctrl+r++ で完全版ダイアログ。**検索 / 置換 / ファイル内検索 / ファイル内置換**
  のタブがあります。
- 複数行の検索・置換欄（++ctrl+enter++ で改行挿入）、置換のキャプチャ参照
  （`$1`〜`$9`）、検索履歴（++up++ / ++down++）に対応。

## 範囲

- **現在のファイル**、**選択範囲**、**開いている全ファイル** から選べます。
- カラム（矩形）選択中は、その列内のみを検索します。

## ファイル内検索 / 置換

- フォルダーを再帰検索。ファイル名フィルター（例 `*.cpp, *.md`）と
  include / exclude 指定が可能です。
- **ファイル内置換** は適用前に全変更の **プレビュー** を表示し、適用はトランザク
  ション的です（書き込み失敗時は全てロールバック）。
