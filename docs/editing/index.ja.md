# 編集

日常的な編集機能です。[検索と置換](search.md)、
[マルチカーソル & カラム](multi-cursor.md)、[Vim モード](vim.md)、
[文字コードと改行](encodings.md)、[大容量ファイル](large-files.md) も参照して
ください。

## 基本

- 複数タブ、分割表示、2ファイルの並列表示。
- 取り消し / やり直し（++ctrl+z++ / ++ctrl+y++）- 連続入力は1ステップ。
- クリップボード履歴 - **Edit → Paste From History**。
- 行へ移動 - ++ctrl+g++。
- オートインデント、対応括弧の強調、**対応括弧へ移動**（++ctrl+bracket-right++）。

## 大きい・構造のあるファイルを読む

- **コード折りたたみ** - 行番号の脇から折りたたみ。Fold All / Unfold All。
- **ワードラップ**、**空白表示**、**カラムルーラー / ガイド**（View メニュー）。
- **ブックマーク** - 切替（++ctrl+f2++）と移動（++f2++）。
- **アウトライン / 関数一覧** - 定義へジャンプ。

## コメントと整形

- **Comment On / Off** - その言語の行コメントを切り替え。
- 大文字小文字変換、タブ&harr;スペース、インデント / 逆インデント、行末空白の除去 -
  Format メニュー。
