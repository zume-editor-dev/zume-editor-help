# Vim モード

Zume Editor には、テキストタブ向けの任意の **Vim 風モーダル編集** モードがあり
ます。既定ではオフで、プラグインは不要です。

## 有効化

- **Edit → Toggle Vim Mode**、または Vim モード中に `:set vim`（解除は
  `:set novim`）。
- 設定は **保存** され、**すべてのテキストタブ** に適用されます。
- Vim モードはテキストタブ専用です。ヘックス・大容量・Git タブでは無効です。

ステータスバーに現在のモードが表示されます：`-- NORMAL --`、`-- INSERT --`、
`-- VISUAL --`、`-- V-LINE --`、`-- V-BLOCK --`。

!!! note "Ctrl ショートカットはそのまま使えます"
    通常のショートカット（++ctrl+s++ 保存、++ctrl+f++ 検索、++ctrl+shift+p++
    コマンドパレットなど）は全モードで有効です。NORMAL モードの2つのキーだけ
    Vim に従います：++ctrl+r++ は **やり直し**、++ctrl+v++ は **ビジュアル
    ブロック** です。

## モード

| 入力 | モード |
| --- | --- |
| `i` `a` `I` `A` `o` `O` | INSERT（文字入力。++esc++ で NORMAL へ戻る） |
| `v` | VISUAL（文字単位） |
| `V` | VISUAL LINE（行単位） |
| ++ctrl+v++ | VISUAL BLOCK（矩形） |
| `:` `/` `?` | コマンドライン（ex / 検索） |

## モーション

`h` `j` `k` `l`（および矢印キー）、`w` `b` `e`、`0` `^` `$`、`gg` `G`、
`{count}G`（行へ移動）、文字検索 `f` `t` `F` `T`（`;` / `,` で繰り返し）。
カウント指定も可能です：`3j`、`42G`、`2w`。

## オペレータとテキストオブジェクト

- オペレータ：`d`（削除）、`c`（変更）、`y`（ヤンク）、`>` / `<`（インデント /
  逆インデント）、`gu` / `gU`（小文字 / 大文字化）。
- モーションと組み合わせる（`dw`、`c$`、`y3j`）か、**2回押し** で行全体に作用
  （`dd`、`yy`、`cc`、`>>`）。
- テキストオブジェクト：`iw` / `aw`、および `i` / `a` ＋ `"` `'` `` ` `` `(`
  `{` `[` `<` — 例：`ci"` は引用符の内側を変更、`da(` は括弧ごと削除。

## アクション

`x` `D` `C` `p` `P` `J` `~` `r{char}`、取り消し `u` / やり直し ++ctrl+r++、
直前の変更を繰り返す `.`。先頭に `"x` を付けると名前付きレジスタ（例：`"ayy`
→ `"ap`）。無名レジスタは通常の `y` / `d` / `p` が使います。

## 検索と置換

- `/パターン`・`?パターン` で前方 / 後方検索、`n` / `N` で繰り返し、`*` / `#`
  でカーソル下の単語を検索。コマンドラインはステータスバーに表示されます。
- `:[range]s/パターン/置換/[g][i]` で置換（全体は `:%s/…/…/g`、現在行は
  `:s/…/…/`）。`:noh` で一致ハイライトを消去。

## ex コマンド

`:w [名前]` 保存、`:q` タブを閉じる（破棄は `:q!`、保存して閉じるは `:wq` /
`:x`）、`:qa` / `:wqa` で全タブ、`:{番号}` で行へ移動、`:set vim` /
`:set novim`。

!!! note
    Vim モードとマルチカーソル / カラムモードは同時には使えません。
