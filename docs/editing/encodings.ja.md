# 文字コードと改行

## 文字コード

開くときに文字コードを自動判定し、ステータスバーに表示します。そこをクリックして
変換するか、**Document → Set Encoding** を使います。

対応する文字コード（抜粋）：

- **Unicode** - UTF-8、UTF-8（BOM付き）、UTF-16 LE/BE、UTF-32 LE/BE
- **日本語** - Shift-JIS（CP932）、EUC-JP
- **CJK** - GBK、Big5、EUC-KR
- **欧文 / キリル / ギリシャ / トルコ / ヘブライ / アラビア / バルト / タイ /
  ベトナム** 各コードページ（ISO-8859-*、Windows-125x ほか）

選択した文字コードで表現できない文字がある場合、黙って失わずに保存前に警告します。

## 改行コード

- **LF** / **CRLF** / **CR** を判定して表示します。混在は「mixed」と表示。
- **Document → Convert Line Endings** で変換。新しく入力する行はファイル自身の
  改行コードに合わせます。
