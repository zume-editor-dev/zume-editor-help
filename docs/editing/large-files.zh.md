# 大文件

Zume Editor 可以打开超大文件（**10&nbsp;GB 乃至更大**），而无需将
整个文件加载到内存中。

- **即时打开**——只读取可见部分；即使是超大文件，第一屏也会在
  约一秒内出现。
- **就地编辑**——局部编辑不会重写整个文件；保存采用流式方式且持久可靠。
- **流式搜索**——字面量搜索和正则表达式搜索会流式贯穿整个文件
  而不会冻结 UI，并支持循环回绕。
- **真实行号**——后台索引会为超大文件提供真实的行号及行/列信息。
- **大文件的十六进制**——[十六进制编辑器](../hex.md)同样适用于大文件。

某些需要将整个文件加载到内存的功能（语法高亮、Git 差异
边栏标记、折叠）在超大文件上会按设计关闭。
