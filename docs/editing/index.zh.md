# 编辑

日常编辑功能。另请参阅 [搜索与替换](search.md)、
[多光标与列模式](multi-cursor.md)、[Vim 模式](vim.md)、
[编码与行尾](encodings.md) 以及 [大文件](large-files.md)。

## 基础

- 多标签页、拆分视图，以及两个文件并排显示。
- 撤销 / 重做（++ctrl+z++ / ++ctrl+y++）——连续的一串输入算作一步。
- 剪贴板历史——**编辑 → 从历史记录粘贴**。
- 转到行——++ctrl+g++。
- 自动缩进、括号匹配，以及**转到匹配的括号**（++ctrl+bracket-right++）。

## 阅读大型或结构化文件

- **代码折叠**——从边栏折叠代码块；全部折叠 / 全部展开。
- **自动换行**、**空白字符显示**，以及**列标尺 / 参考线**（位于
  视图菜单中）。
- **书签**——切换（++ctrl+f2++）并在书签之间跳转（++f2++）。
- **大纲 / 函数列表**——跳转到文件中的定义。

## 注释与格式化

- **开启 / 关闭注释**可按文件的语言切换行注释。
- 大小写转换、制表符&harr;空格、缩进 / 取消缩进、去除行尾空白——
  位于格式菜单中。
