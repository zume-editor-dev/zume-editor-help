# Editing

The everyday editing features. See also [Search & Replace](search.md),
[Multi-cursor & Column](multi-cursor.md), [Encodings & Line Endings](encodings.md)
and [Large Files](large-files.md).

## Basics

- Multiple tabs, split view, and two files side by side.
- Undo / redo (++ctrl+z++ / ++ctrl+y++) - a run of typing is one step.
- Clipboard history - **Edit → Paste From History**.
- Go to line - ++ctrl+g++.
- Auto-indent, bracket matching, and **Go to Matching Bracket** (++ctrl+bracket-right++).

## Reading large or structured files

- **Code folding** - fold blocks from the gutter; Fold All / Unfold All.
- **Word wrap**, **whitespace display**, and a **column ruler / guide** (in the
  View menu).
- **Bookmarks** - toggle (++ctrl+f2++) and jump between them (++f2++).
- **Outline / function list** - jump to definitions in the file.

## Comments and formatting

- **Comment On / Off** toggles line comments for the file's language.
- Case transforms, tabs&harr;spaces, indent / dedent, trim trailing whitespace -
  in the Format menu.
