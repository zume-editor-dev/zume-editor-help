# 编码与行尾

## 编码

Zume Editor 在打开文件时会检测编码，并在状态栏中显示。点击状态栏中的
编码即可转换，或使用**文档 → 设置编码**。

支持的编码包括：

- **Unicode**——UTF-8、带 BOM 的 UTF-8、UTF-16 LE/BE、UTF-32 LE/BE。
- **日语**——Shift-JIS（CP932）、EUC-JP。
- **CJK**——GBK、Big5、EUC-KR。
- **西欧 / 西里尔 / 希腊 / 土耳其 / 希伯来 / 阿拉伯 / 波罗的海 / 泰 /
  越南**代码页（ISO-8859-*、Windows-125x 等）。

如果某个字符无法在所选编码中表示，应用会在保存前向你发出警告，
而不会悄无声息地丢失它。

## 行尾

- 检测并显示 **LF**、**CRLF** 或 **CR**；混合行尾的文件会报告为混合。
- 使用**文档 → 转换行尾**进行转换。你输入的新行会使用
  文件自身的行尾。
