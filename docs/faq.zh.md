# 常见问题

**有免费试用吗？**
有 —— 30 天，所有功能，无需账户。请参阅 [激活](activation.md)。

**价格是多少？**
每年 $49，在我们的网站上购买（所有平台通用）。

**一个许可证可以在多少台计算机上使用？**
最多 3 台你自己的计算机，可任意组合 Windows、macOS 和 Linux。

**我可以把许可证迁移到新计算机上吗？**
可以 —— 在旧计算机上执行 **Help → Deactivate This Device**，然后在新计算机上
激活。

**它能离线工作吗？**
可以。它在激活时会在线验证，并会偶尔重新检查，但在此期间可以
离线工作。

**支持哪些操作系统？**
Windows 10/11、macOS 和 Linux。

**如何取消订阅，能退款吗？**
通过 **Help → Manage Subscription** 取消。我们提供 14 天退款保证 ——
请参阅 [激活](activation.md) 和 [支持](support.md)。

**我的设置和日志存储在哪里？**
存储在你本地的机器上 —— 请参阅 [故障排查](troubleshooting.md)。
