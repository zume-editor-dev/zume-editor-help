# よくある質問（FAQ）

**無料体験はありますか？**
はい。30日間・全機能・アカウント不要です。[ライセンス認証](activation.md) を参照。

**価格は？**
年額49ドル。公式サイトで購入します（全OS共通）。

**1ライセンスで何台使えますか？**
ご本人の最大3台まで（Windows / macOS / Linux の組み合わせ可）。

**新しいPCへライセンスを移せますか？**
はい。旧PCで **Help → Deactivate This Device**、新PCで認証してください。

**オフラインでも使えますか？**
はい。認証時にオンライン確認し、時々再確認しますが、その間はオフラインで動作します。

**対応OSは？**
Windows 10/11・macOS・Linux。

**解約・返金は？**
解約は **Help → Manage Subscription** から。14日間の返金保証があります。
[ライセンス認証](activation.md) と [サポート](support.md) を参照してください。

**設定やログはどこに保存されますか？**
お使いの端末内です。[トラブルシューティング](troubleshooting.md) を参照してください。
