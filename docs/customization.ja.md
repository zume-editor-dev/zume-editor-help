# カスタマイズ

主な設定は **Tools → Settings** から、または設定ファイルを直接編集できます。

- **テーマ** - ライト / ダーク / ハイコントラスト、または自作テーマファイル。OSの
  ハイコントラスト設定に追従させることもできます。
- **ツールバー** - 表示するコマンドの選択と並べ替え。
- **メニュー** - 組み込みメニューへコマンドを追加。
- **キーバインド** - コマンドを好みのショートカットへ再割り当て。
- **言語** - 英語 / 日本語（今後追加予定）。
- **フォント & ズーム** - ++ctrl+plus++ / ++ctrl+minus++ / ++ctrl+0++、Ctrl+ホイール。
- **レイアウト** - ペイン分割、ドッキングパネル、ファイルパネルの分割、ファイル種別
  ごとのワードラップ など。
