# Updating

## Microsoft Store (Windows)

If you installed from the Microsoft Store, updates are delivered and installed
automatically by the Store.

## Standalone / macOS / Linux

- Use **Help → Check for Updates** to check manually. If a newer version is
  available, the app points you to the download page.
- Zume Editor does not download or replace itself silently; you choose when to
  update.

Your settings, sessions and license carry over across updates.
