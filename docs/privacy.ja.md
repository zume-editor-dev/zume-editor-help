# プライバシー & セキュリティ

- **既定でテレメトリなし。** 明示的に同意しない限り、ファイルや使用状況を送信する
  ことはありません。
- **データはローカルに保持。** ファイル・設定・最近使った項目・セッションは、お使いの
  端末に保存されます。
- **資格情報を保護。** SSH / SFTP・FTP / データベース / クラウドのパスワードは、OSの
  セキュアな資格情報ストア（Windows資格情報マネージャー、macOSキーチェーン、Linux
  Secret Service）に保存され、平文の設定ファイルには保存しません。
- **ライセンス確認** は当社の認証サーバーにのみ、ライセンス検証の目的でのみ通信します。
  [ライセンス認証](activation.md) を参照してください。
