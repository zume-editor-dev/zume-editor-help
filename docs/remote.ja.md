# リモートファイル（SFTP / FTP / FTPS）

リモートサーバー上のファイルを直接編集できます。

1. **Remote → Connect** - 方式（**SFTP** / **FTP** / **FTPS**）を選び、ホスト・ポート・
   ユーザー・パスワード（SFTPはSSH鍵も可）を入力。
2. サイドバーがリモートブラウザーになります。フォルダーをクリックで移動、ファイルを
   クリックでタブに開きます。
3. **保存**（++ctrl+s++）でサーバーへアップロードします。

- **ホスト鍵の信頼** - SFTPはTOFU（初回信頼）。未知の鍵のフィンガープリントを一度だけ
  確認します。FTPSの証明書に問題がある場合は続行前に確認します。
- **接続の保存** - 接続プロファイルを保存できます（パスワードは保存を選んだ場合のみ、
  かつOSのセキュア保管領域にのみ保存）。
- 複数の接続を同時に開け、それぞれ独立したタブになります。

SSHシェルは [ターミナル & SSH](terminal-ssh.md)、クラウドストレージは
[クラウドドライブ](clouddrive.md) を参照してください。
