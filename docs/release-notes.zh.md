# 发行说明

当前版本显示在应用中（**Help → About**）。这是一个**免费的公开测试版**——所有
功能在 **2027-03-31** 之前均可免费使用。

下载请见[安装](installation.md)页面。请在
[GitHub](https://github.com/zume-editor-dev/zume-editor-help/issues) 上报告
缺陷和需求。

## 0.30.0 — 首个公开测试版

Zume Editor 面向 **Windows、macOS 和 Linux** 的首个公开测试版。

**亮点**

- **超大文件**——打开、搜索、编辑和保存 10&nbsp;GB 以上的文件，首屏几乎即时
  呈现，而无需将其加载到内存中。
- **十六进制编辑器**——偏移量 / ASCII / EBCDIC 列、字节查找与替换、
  模板、补丁（IPS / BPS / UPS / bsdiff / VCDIFF）。
- **Git 客户端**——暂存 / 提交、分支、日志图、差异、冲突
  解决、抓取 / 拉取 / 推送、工作树和 LFS。
- 可停靠面板中的**终端与 SSH** shell，以及通过 SFTP / FTP / FTPS 进行的
  **远程编辑**。
- **数据库工具**、双窗格**差异与合并**，以及 **CSV 网格**编辑。
- **Markdown / HTML 实时预览**、**格式与编码转换**、一个 **CLI**
  （`zume-cli`），以及面向 AI 代理的 **MCP 服务器**。
- **地理数据转换**（MAP）：DMS、geohash、地图瓦片、GeoJSON / WKT /
  KML / GPX，以及日本平面直角坐标系。
- 日常编辑：语法高亮、代码折叠、大纲、**多光标**、
  **列（块）模式**、搜索与替换、分屏视图、宏、Lua 脚本和
  会话恢复。

一个许可证（针对即将发布的稳定版）涵盖全部三个平台。

### 测试版更新 — 2026 年 10 月

- **面向 AI 代理的 MCP，大幅扩展**——`zume-mcp` 服务器现在将编辑器的大多数
  引擎作为工具暴露：跨文件搜索与替换、地图数据转换（geo）、转换工具箱、
  zip/tar 归档、二进制补丁、Markdown→HTML、大纲/符号列表、文件夹比较、流式
  大文件搜索、Redis/MongoDB、只读 Git、云存储、沙盒化的 Lua 脚本，
  以及安全分析（熵值、CyberChef 风格的转换配方、一个 YARA 规则子集扫描器）。
  一个新的沙盒（`ZUME_MCP_ROOTS` / `ZUME_MCP_READONLY`）限定了代理可以读取
  或更改的范围。参见 [MCP](mcp.md#tools)。
- **Markdown 预览表格**——GFM 竖线表格现在渲染为带边框的网格，
  **单元格内支持粗体 / 斜体 / 代码 / 链接**，并支持按列对齐。
  HTML 表格在所有平台上都能在预览中渲染。
- **处理中光标**——在超大文件正在打开时，以及文件内搜索或替换正在运行时，
  会显示一个忙碌光标。
- **对话框优化**——过长的对话框标题不再换行或与关闭按钮重叠，Theme 对话框的
  **X** 按钮和标题悬停已修复，Settings 对话框的滚动条会显示抓取光标。
- **稳定性**——修复了使用终端 / SSH 面板后可能发生的一处崩溃。
- 各平台上的若干较小修复。

### 测试版更新 — 2026-10-15（刷新版构建）

Windows、macOS 和 Linux 的安装包从同一代码树重新构建；版本仍为 0.30.0。请从
安装页面重新下载以获取它们。

- **转换配方对话框会列出每个步骤**——Code → Apply Convert
  Recipe… 现在会在其字段下方显示完整的步骤列表：带键名的原语
  （`xor:` / `rc4:` / `rot:`）、无参数的原语、短名称，以及按组归类的每个
  转换器 id，因此无需记忆任何内容。文档所用的短名称（`from_base64`、
  `to_base64`、`from_base32`、`to_base32`、`gunzip`、`gzip`、`url_decode`、
  `url_encode`）现在已被接受——此前，引擎会将它们作为未知步骤拒绝。参见
  [转换配方](security.md#transform-recipes)。
- **编辑器中的 YARA 扫描**——Code → YARA Scan… 接受一个规则文件，扫描
  活动文档，并在结果面板中列出每个匹配；点击某一行可跳转到其所在行。该配方
  还新增了此前仅限 MCP 的转换原语（`xor`、`rot`、`rc4`、`base58` / `base85`、
  十六进制）。
- **预览中的删除线**——`~~text~~` 以及 `<del>` / `<s>` /
  `<strike>` 现在会在 Markdown / HTML 预览中渲染为删除线
  （Windows 和 Linux；macOS 目前将它们绘制为纯文本）。
- **macOS**——使用上述修复及最新的 macOS 端优化重新构建了镜像。

### 测试版更新 — 2026-10-21（刷新版构建）

从同一代码树重新构建（仍为 0.30.0），包含一个大型逆向工程批次和浮动面板。请从
安装页面重新下载以获取它们。

- **逆向工程**——一套新的 **Code** 菜单工具可结构化地读取可执行文件，且绝不
  运行它们：**Executable Info**（PE / ELF / Mach-O——
  头部、带熵值的节区、导入 / 导出、资源、加固措施），
  **Disassemble Executable**（Capstone：x86 / 64、ARM、Thumb、AArch64）、
  **Cross-References** 和函数恢复，以及可选的反编译器——它们会调用你安装的
  工具——**Ghidra**、**ILSpy**（.NET）和 **javap + CFR**
  （Java）。新的 **Objective-C / Swift Interface** 恢复功能会读取 Mach-O 的
  运行时元数据（类、方法、实例变量、属性、Swift 类型和去混淆后的符号）——在
  macOS / iOS 二进制文件上最为有用。MCP 服务器暴露了相同的引擎（`pe_info`、
  `elf_info`、`macho_info`、`disassemble`、
  `xrefs`、`functions`、`decompile`）。参见 [安全分析](security.md)。
- **浮动面板**——任何停靠面板（终端、结果、FTP / SFTP / SSH、
  比较）都可以浮动到它自己的窗口中——例如把一个终端放到第二台显示器上——然后
  重新停靠，其实时内容仍会持续更新。
  右键单击一个面板的标签页可获得 **Float Tab** 和 **Move to Right / Bottom**。
  参见 [快速入门](getting-started.md#panels-docking-moving-and-floating)。
- **macOS**——逆向工程工具套件和浮动面板已在 macOS 构建上验证；
  使用最新的 Mac 端优化重新构建了镜像。
- 各平台上的若干较小修复。

### 测试版更新 — 2026-10-22（刷新版构建）

从同一代码树重新构建（仍为 0.30.0）。请从安装
页面重新下载以获取它们。

- **设置路径修复（Windows）**——包含反斜杠的文件系统路径——
  **Ghidra** 和 **ILSpy** 的安装文件夹、ILSpy 缓存和恢复
  目录——在 `settings.json` 重新加载时会被损坏（例如
  `C:\root\ghidra` 变成了 `C:rootghidra`），这会导致 **Code → Decompile** 失败
  并报 “analyzeHeadless not found”。现在设置路径可以正确地往返保存，并且
  更新后能正确读取现有的 `settings.json`，无需重新输入这些路径。
- **文件夹面板滚动修复**——在文件夹面板已滚动到底部之后，
  缩小结果面板会使该面板变大，并使其行滚动到顶部之外、滚动条消失、
  无法返回。现在滚动偏移量会被限制，因此行永远不会被搁浅。
- 所有平台都从同一次提交重新构建。
