# リリースノート

現在のバージョンはアプリ内（**Help → About**）で確認できます。本バージョンは
**無料の公開ベータ版**で、**2027年3月31日まで**すべての機能を無料でご利用いただけます。

ダウンロードは[インストール](installation.md)ページをご覧ください。不具合報告・ご要望は
[GitHub](https://github.com/zume-editor-dev/zume-editor-help/issues) までお寄せください。

## 0.30.0 — 初の公開ベータ

**Windows・macOS・Linux** 対応、Zume Editor 初の公開ベータです。

**主な機能**

- **巨大ファイル対応** — 10&nbsp;GB 超のファイルも、メモリに丸ごと読み込まずに、
  初回表示ほぼ一瞬で開く・検索・編集・保存。
- **HEX エディタ** — オフセット / ASCII / EBCDIC 列、バイト検索・置換、テンプレート、
  パッチ（IPS / BPS / UPS / bsdiff / VCDIFF）。
- **Git クライアント** — ステージ／コミット、ブランチ、ログのグラフ、Diff、
  コンフリクト解決、fetch / pull / push、ワークツリー、LFS。
- **ターミナル・SSH** シェル（ドッキング可能なパネル）、**SFTP / FTP / FTPS**
  でのリモート編集。
- **データベースツール**、2 ペインの **Diff・マージ**、**CSV グリッド**編集。
- **Markdown / HTML ライブプレビュー**、**フォーマット・エンコーディング変換**、
  **CLI**（`zume-cli`）、AI 連携の **MCP サーバー**。
- **地理データ変換**（MAP）：DMS、ジオハッシュ、地図タイル、
  GeoJSON / WKT / KML / GPX、平面直角座標系。
- 日常の編集：シンタックスハイライト、コード折りたたみ、アウトライン、
  **マルチキャレット**、**カラム（ブロック）モード**、検索・置換、分割ビュー、
  マクロ、Lua スクリプト、セッション復元。

1 ライセンス（今後の正式版）で 3 プラットフォームすべてに対応します。

### ベータ版の更新 — 2026年10月

- **AI エージェント向け MCP を大幅拡張** — `zume-mcp` サーバーがエディターの
  ほとんどのエンジンをツールとして公開：複数ファイル横断の検索・置換、地理データ
  変換（geo）、変換ツールボックス、zip/tar アーカイブ、バイナリパッチ、
  Markdown→HTML、アウトライン / シンボル一覧、フォルダー比較、大容量ファイルの
  ストリーム検索、Redis/MongoDB、読み取り専用 Git、クラウドストレージ、
  サンドボックス Lua スクリプト、セキュリティ解析（エントロピー、CyberChef 風の
  変換レシピ、YARA ルールのサブセット走査）。新しいサンドボックス（`ZUME_MCP_ROOTS` /
  `ZUME_MCP_READONLY`）でエージェントが読み書きできる範囲を制限できます。
  詳細は [MCP](mcp.md#tools)。
- **Markdown プレビューのテーブル** — GFM のパイプテーブルが罫線付きグリッドで
  表示され、**セル内の太字 / 斜体 / コード / リンク**や列ごとの配置に対応。
  HTML のテーブルも全プラットフォームのプレビューで表示されます。
- **処理中カーソル** — 巨大ファイルのオープン中、およびファイル内の検索・置換の
  実行中に、処理中（待機）カーソルを表示。
- **ダイアログの改善** — 長いダイアログのタイトルが折り返したり閉じるボタンに
  重なったりしないよう修正、テーマダイアログの **X** ボタンとヘッダーのホバーを修正、
  設定ダイアログのスクロールバーにカーソルを表示。
- **安定性** — ターミナル / SSH パネル使用後に発生し得たクラッシュを修正。
- その他、全プラットフォームで細かな修正。

### ベータ版の更新 — 2026年10月15日（ビルド更新）

Windows / macOS / Linux のパッケージを同じソースから再ビルドしました。バージョン
番号は 0.30.0 のままです。インストールページから再ダウンロードしてください。

- **変換レシピのダイアログに全ステップ一覧** — コード → 変換レシピを適用… の
  入力欄の下に、使えるステップをすべて表示するようにしました：引数ありの
  プリミティブ（`xor:` / `rc4:` / `rot:`）、引数なしのもの、短い別名、そして
  分類ごとのコンバーター ID。名前を覚えておく必要はありません。ドキュメントで
  使っていた短い別名（`from_base64`、`to_base64`、`from_base32`、`to_base32`、
  `gunzip`、`gzip`、`url_decode`、`url_encode`）も受け付けるようになりました
  （以前は不明なステップとして拒否していました）。詳細は
  [変換レシピ](security.md#transform-recipes)。
- **エディター内の YARA スキャン** — コード → YARA スキャン… でルールファイルを
  指定すると、アクティブな文書を走査して一致を結果パネルに一覧し、行をクリック
  するとその行へ移動します。レシピにも、これまで MCP 専用だった変換プリミティブ
  （`xor`、`rot`、`rc4`、`base58` / `base85`、16 進）が加わりました。
- **プレビューの打ち消し線** — `~~text~~` と `<del>` / `<s>` / `<strike>` が
  Markdown / HTML プレビューで打ち消し線付きで表示されます（Windows と Linux。
  macOS は当面プレーンテキストで表示）。
- **macOS** — 上記の修正と macOS 側の最新の調整を含めてイメージを再作成しました。

### ベータ版の更新 — 2026年10月21日（ビルド更新）

同じツリーから再ビルド（バージョンは 0.30.0 のまま）。リバースエンジニアリングの
大きなバッチとフローティングパネルを含みます。インストールページから再ダウンロード
してください。

- **リバースエンジニアリング** — 実行ファイルを構造的に読む（実行はしない）新しい
  **コード**メニュー群: **実行ファイル情報**（PE / ELF / Mach-O — ヘッダ、
  エントロピー付きセクション、インポート / エクスポート、リソース、ハードニング）、
  **実行ファイルの逆アセンブル**（Capstone: x86 / 64・ARM・Thumb・AArch64）、
  **相互参照**と関数復元、そしてユーザー導入ツールへ委譲する任意の逆コンパイラ
  **Ghidra**・**ILSpy**（.NET）・**javap + CFR**（Java）。新しい
  **Objective-C / Swift インターフェース**復元は Mach-O のランタイムメタデータ
  （クラス、メソッド、ivar、プロパティ、Swift 型とデマングルしたシンボル）を読みます
  — macOS / iOS バイナリで特に有用です。MCP サーバーも同じエンジンを公開します
  （`pe_info`、`elf_info`、`macho_info`、`disassemble`、`xrefs`、`functions`、
  `decompile`）。[セキュリティ分析](security.md) を参照。
- **フローティングパネル** — 任意のドックパネル（ターミナル、結果、FTP / SFTP /
  SSH、比較）を独立ウィンドウに切り離し（例: ターミナルを別モニタへ）、内容を
  ライブ更新したまま再ドックできます。パネルのタブを右クリックで
  **タブを切り離す**・**右へ移動 / 下へ移動**。
  [はじめに](getting-started.md) を参照。
- **macOS** — リバースエンジニアリング群とフローティングパネルは macOS ビルドで
  検証済み。最新の macOS 側の調整を含めてイメージを再作成しました。
- 全プラットフォームで細かな修正。
