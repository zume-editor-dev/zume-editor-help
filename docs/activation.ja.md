# ライセンス認証

Zume Editor は無料体験付きの有料アプリです。公式サイトでサブスクを購入し（全OS
共通）、メールでお送りするライセンスキーでアプリを認証します。

## 無料体験

初回起動から **30日間の無料体験** が始まり、全機能が使えます（アカウント・支払い
不要）。体験期間が終わったら、ライセンスを購入して継続利用できます。

## ライセンスの購入

公式サイトで **年額 49 ドル** で購入できます（Windows / macOS / Linux いずれも
Webから）。決済は当社のリセラー / 支払い代行事業者（Merchant of Record）である
**Paddle** が処理します。購入後、**ライセンスキー**（形式
`ZUME-XXXX-XXXX-XXXX-XXXX`）をメールでお送りします。

## 認証の手順

1. Zume Editor を開く
2. **Help → Activate License**
3. 購入時の **メールアドレス** と **ライセンスキー** を入力
4. **Activate** をクリック

認証時にオンラインで確認し、以降はオフラインでも動作します。時々バックグラウンドで
静かに再確認します。

## 1ライセンスで最大3台

1つのライセンスで、**ご本人の最大3台**（Windows / macOS / Linux の組み合わせ可）で
利用できます。商用利用も可能です。

### 別のPCへ移すには

3台の上限に達した場合や買い替えの場合：

1. 旧PCで **Help → Deactivate This Device**
2. 新PCで **Help → Activate License**（同じメールとキー）

## サブスクの管理・解約

**Help → Manage Subscription** から、安全な Paddle のポータルページを開けます。
支払い情報の変更や解約が可能です。解約すると次回以降の更新が止まり、支払い済みの
期間終了まではご利用いただけます。

## 返金

**14日間の返金保証** があります。ご満足いただけない場合は、購入後14日以内に
[support@smolt-stage.com](mailto:support@smolt-stage.com) までご連絡いただければ
全額返金します。詳しくは [サポート](support.md)。

## サブスク終了時の挙動

解約または更新の失敗後は、短い猶予期間のあいだ動作し、その後に再認証を促します。
ファイルがロックされたり書き換えられることはありません。更新までの間、ライセンス
対象の機能が停止するだけです。
