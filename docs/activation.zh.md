# 激活与许可

Zume Editor 是一款带有免费试用的付费应用。你在我们的网站上购买订阅（所有平台通用），
并使用我们通过邮件发送给你的许可证密钥激活应用。

## 免费试用

首次启动会开启一个 **30 天免费试用**，所有功能均已解锁。无需
账户或付款。试用结束后，购买许可证即可继续使用编辑器。

## 购买许可证

在网站上以 **$49 / 年** 购买（Windows、macOS 和 Linux 都通过
网站购买）。付款由我们的分销商 / 记录商（Merchant of Record）**Paddle** 处理。
付款后，你会通过邮件收到一个 **许可证密钥**（格式为
`ZUME-XXXX-XXXX-XXXX-XXXX`）。

## 激活

1. 打开 Zume Editor。
2. **Help → Activate License**。
3. 输入你购买时使用的 **邮箱** 和 **许可证密钥**。
4. 点击 **Activate**。

应用会在线验证你的许可证，之后即可离线使用；它会不时在后台
悄悄重新检查。

## 一个许可证，最多 3 台计算机

单个许可证可在 **最多 3 台你自己的计算机** 上使用（可任意组合 Windows、
macOS 和 Linux），供一个具名用户使用。允许商业使用。

### 迁移到另一台计算机

如果你达到了 3 台设备的上限或更换了机器：

1. 在旧计算机上：**Help → Deactivate This Device**。
2. 在新计算机上：使用相同的邮箱和密钥执行 **Help → Activate License**。

## 管理或取消订阅

**Help → Manage Subscription** 会打开你的安全 Paddle 门户页面，你可以在那里
更新付款信息或取消订阅。取消订阅会停止未来的续费；你在已付费的
周期结束前仍可继续使用。

## 退款

我们提供 **14 天退款保证**。如果你不满意，请在购买后 14 天内发送邮件至
[support@smolt-stage.com](mailto:support@smolt-stage.com)，即可获得全额退款。请参阅 [支持](support.md)。

## 订阅结束时

当订阅被取消或续费失败时，应用会在一个短暂的宽限期内继续工作，
之后会提示你重新激活。你的文件永远不会被
锁定或更改 —— 只是编辑器的许可功能会停止，直到你续费为止。
