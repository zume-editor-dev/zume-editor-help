# Keyboard Shortcuts

A selection of common shortcuts. See the command palette (++ctrl+shift+p++) for the
full list - each command shows its shortcut - and [Customization](customization.md)
to rebind them.

| Action | Shortcut |
| --- | --- |
| Command palette | ++ctrl+shift+p++ |
| New / close / reopen tab | ++ctrl+t++ / ++ctrl+w++ / ++ctrl+shift+t++ |
| Open / Save / Save As | ++ctrl+o++ / ++ctrl+s++ / ++ctrl+shift+s++ |
| Undo / Redo | ++ctrl+z++ / ++ctrl+y++ |
| Cut / Copy / Paste | ++ctrl+x++ / ++ctrl+c++ / ++ctrl+v++ |
| Find / Find next / previous | ++ctrl+f++ / ++f3++ / ++shift+f3++ |
| Find & Replace dialog | ++ctrl+r++ |
| Go to line | ++ctrl+g++ |
| Toggle file panel | ++ctrl+b++ |
| Split pane / switch pane | ++ctrl+backslash++ / ++f6++ |
| Hex view | ++ctrl+shift+h++ |
| Zoom in / out / reset | ++ctrl+plus++ / ++ctrl+minus++ / ++ctrl+0++ |
| Toggle fullscreen | ++f11++ |

!!! note
    On macOS, use ++cmd++ where this table shows ++ctrl++.
