# データベース

エディター内からデータベースへ接続し、スキーマの参照やクエリ実行ができます。結果は
グリッドで表示されます。

## 接続できるデータベース

**SQL**

| エンジン | 備考 | 既定ポート |
| --- | --- | --- |
| **SQLite** | ローカルのデータベースファイル、または新規 / インメモリ | — (ファイル) |
| **MySQL / MariaDB** | MySQL 互換サーバー（例: TiDB）も可 | 3306 |
| **PostgreSQL** | PostgreSQL 互換サーバーも可 | 5432 |
| **Microsoft SQL Server** | ネイティブ TDS プロトコル | 1433 |

**NoSQL**

| エンジン | 備考 | 既定ポート |
| --- | --- | --- |
| **Redis** | RESP プロトコル | 6379 |
| **MongoDB** | MongoDB ワイヤプロトコル | 27017 |

## 接続のしかた

- **SQLite** - データベースファイル（`.db` / `.sqlite` など）を開く、または新規作成。
- **サーバー系エンジン** - ホスト・ポート（既定のままにするとエンジン標準ポートを使用）・
  ユーザー・パスワード、任意で既定データベースを指定します。ネットワーク接続は
  **既定で TLS を使用**します。

!!! tip "資格情報は保護されます"
    接続パスワードは OS のセキュアな資格情報ストア（Windows資格情報マネージャー、macOS
    キーチェーン、Linux Secret Service）に保存され、平文の設定・セッションファイルには
    保存されません。[プライバシー & セキュリティ](privacy.md) を参照してください。

## 接続後の操作

- **スキーマブラウザー** - テーブル / ビュー（列・型・主キー・インデックス）、および
  対応エンジンでは関数・ストアドプロシージャ・トリガー・シーケンスを表示。
- **SQL 実行** - 文を書いて実行すると、結果がグリッドに表示されます（大きな結果は上限で
  打ち切られ *truncated* と表示）。データ変更文では **影響行数** と実行時間を表示します。
- **インライン編集** - 結果セルを編集できます。書き込みはパラメータ化された文を使うため、
  値（テキスト・数値・BLOB・NULL）が手動クオートなしで安全にバインドされます。
- **NoSQL** - Redis / MongoDB 接続では、コマンド / クエリを実行し、同じパネルに結果を
  表示します。
