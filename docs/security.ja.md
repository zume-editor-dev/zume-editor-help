# セキュリティ解析

Zume Editor には、バイナリ診断・データ変換・シグネチャ走査のツールがあり、
リバースエンジニアリング、CTF、認可されたセキュリティ作業に役立ちます。いずれも
[MCP サーバー](mcp.md#tools)経由で AI エージェントからヘッドレスに利用できます
（`entropy`・`transform`・`yara_scan` ツール）。

## YARA スキャン

**コード → YARA スキャン…** は、YARA ルールでアクティブ文書を走査します。

1. コマンドを実行（コマンドパレットにもあります）。
2. `.yar` / `.yara` ルールファイルのパスを入力。
3. 一致は結果パネルに `rule  $string  line N @ offset` の形で一覧表示されます。
   行をクリック（または F4）するとその行へジャンプします。

対応する YARA のサブセット：テキスト、hex（`{ 4D 5A ?? 00 }`、`??` / `?`
ワイルドカード）、`/regex/` 文字列（修飾子 `nocase` / `wide` / `ascii` /
`fullword`）、条件 `all`/`any`/`N of them`、`N of ($a*)`、`#count`、`$s at N`、
`filesize`、`and` / `or` / `not`。完全な libyara エンジンではありません
（`pe` / `hash` / `math` モジュールは非対応）。

## 変換レシピ

**コード → 変換レシピの適用…** は、選択範囲（または文書全体）に対して変換を
左から右へ連結して適用します。ステップは `|`（またはスペース / カンマ）で区切り、
引数はコロンの後に書きます。例：

```
from_base64 | xor:cafe | gunzip
```

[ファイル変換](convert.md)の各コンバーター（base64、gzip、URL、JWT デコード等）に
加えて、`xor:<鍵>`、`rot:<n>` / `rot13`、`not`、`reverse`、`rc4:<鍵>`、
`base58.encode` / `base58.decode`、`base85.encode` / `base85.decode`、
`from_hex` / `to_hex` のプリミティブが使えます。鍵は `hex:cafe` または
`str:secret`（素の値は、16 進に見える場合は 16 進として扱います）。

## エントロピー

[HEX / バイナリエディタ](hex.md)のエントロピーマップとオーバービューストリップが、
ファイルを領域ごとに Shannon エントロピー（0–8 bit/byte）で表示するため、パックや
暗号化された領域が目立ちます。

## シークレットの検出

**コード → シークレットを検出** は、文書内の疑わしいシークレット（API キー、
トークン、秘密鍵、資格情報）を行番号付きで一覧し、行をクリックするとジャンプします。
**編集 → 選択範囲をマスク** は選択テキストを伏せ字にします。
