# 隐私与安全

- **默认无遥测。** 除非你明确选择启用，否则 Zume Editor 不会将你的文件或
  使用数据发送到任何地方。
- **你的数据保留在本地。** 文件、设置、最近列表和会话都存储在
  你自己的机器上。
- **凭据受到保护。** SSH、SFTP/FTP、数据库和云密码都
  保存在操作系统的安全凭据存储中（Windows Credential
  Manager、macOS Keychain、Linux Secret Service）—— 绝不会保存在明文设置文件中。
- **许可证检查** 只会联系我们的激活服务器，且仅用于验证你的
  许可证。请参阅 [激活与许可](activation.md)。
