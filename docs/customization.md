# Customization

Open **Tools → Settings** for the main options, or edit the settings file directly.

- **Themes** - Light, Dark, High Contrast, or your own theme file. The app can
  follow your OS high-contrast setting.
- **Toolbar** - choose which commands appear, and reorder them.
- **Menus** - add commands to the built-in menus.
- **Keybindings** - rebind commands to your own shortcuts.
- **Language** - English or Japanese (more to come).
- **Font & zoom** - ++ctrl+plus++ / ++ctrl+minus++ / ++ctrl+0++, or Ctrl+wheel.
- **Layout** - split panes, dockable panels, a split file panel, word-wrap by file
  type, and more.
