# Database

Connect to a database, browse it and run queries from inside the editor.

- Create a connection (host, port, user, password - stored in your OS secure store).
- Browse databases, tables and schema.
- Write and run SQL, and view the results in a grid.

!!! tip
    Credentials are kept in the operating system's secure credential store, never
    in plain settings or session files.
