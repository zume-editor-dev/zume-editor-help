# 地図（地理データ変換）

地理空間データの変換・計測をエディター内で行えます（**Tools → Geo**）。

## フォーマット変換

**GeoJSON / WKT / KML / GPX / CSV**（点データ）を相互変換します。内部で中立モデルを
使うため、どの形式からどの形式へも変換できます。

## 座標と変換

- **DMS &harr; 10進** 度、**geohash** のエンコード / デコード。
- **スリッピーマップのタイル**（z/x/y、Bing quadkey、バウンディングボックス）。
- **平面直角座標系**（JGD2011、1〜19系）&harr; 緯度経度。

## 計測

- GeoJSON / WKT ジオメトリの測地的な **距離** と **面積**。

これらはコマンドラインからも利用できます。[CLI → geo](cli.md) を参照してください。
