# MCP（AI連携）

Zume Editor は **MCP（Model Context Protocol）サーバー** として動作でき、対応する
AIクライアントがエディターのコマンド経由で読み取り・編集できます。

- 設定でMCPサーバーを有効化します。
- MCP対応クライアントの接続先を Zume Editor に設定します。
- AIは利用者と同じ文書・コマンドのパイプラインを通して動作するため、編集は取り消し
  可能で安全です。

!!! info
    MCPは、AIアシスタントをツールやデータソースに接続するためのオープンなプロトコルです。
