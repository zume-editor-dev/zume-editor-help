# Zume Editor ヘルプ

**Zume Editor** のヘルプへようこそ。Zume Editor は **Windows / macOS / Linux**
対応の高速ネイティブなテキスト・コード・バイナリエディターで、超大容量ファイル
（10&nbsp;GB 超）や実務の開発ワークフローを想定して作られています。
