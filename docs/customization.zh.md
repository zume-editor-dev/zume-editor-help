# 自定义

打开 **Tools → Settings** 查看主要选项，或直接编辑设置文件。

- **主题** —— Light、Dark、High Contrast，或你自己的主题文件。应用可以
  跟随你操作系统的高对比度设置。
- **工具栏** —— 选择显示哪些命令，并重新排序。
- **菜单** —— 向内置菜单中添加命令。
- **键绑定** —— 将命令重新绑定到你自己的快捷键。
- **语言** —— 英语或日语（更多语言即将推出）。
- **字体与缩放** —— ++ctrl+plus++ / ++ctrl+minus++ / ++ctrl+0++，或 Ctrl+滚轮。
- **布局** —— 拆分窗格、可停靠面板、拆分文件面板、按文件类型
  自动换行等等。
