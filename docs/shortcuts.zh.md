# 键盘快捷键

一些常用快捷键的选集。完整列表请查看命令面板（++ctrl+shift+p++）——
每个命令都会显示其快捷键 —— 以及 [自定义](customization.md)
了解如何重新绑定它们。

| 操作 | 快捷键 |
| --- | --- |
| 命令面板 | ++ctrl+shift+p++ |
| 新建 / 关闭 / 重新打开标签页 | ++ctrl+t++ / ++ctrl+w++ / ++ctrl+shift+t++ |
| 打开 / 保存 / 另存为 | ++ctrl+o++ / ++ctrl+s++ / ++ctrl+shift+s++ |
| 撤销 / 重做 | ++ctrl+z++ / ++ctrl+y++ |
| 剪切 / 复制 / 粘贴 | ++ctrl+x++ / ++ctrl+c++ / ++ctrl+v++ |
| 查找 / 查找下一个 / 上一个 | ++ctrl+f++ / ++f3++ / ++shift+f3++ |
| 查找并替换对话框 | ++ctrl+r++ |
| 跳转到行 | ++ctrl+g++ |
| 切换文件面板 | ++ctrl+b++ |
| 拆分窗格 / 切换窗格 | ++ctrl+backslash++ / ++f6++ |
| 十六进制视图 | ++ctrl+shift+h++ |
| 放大 / 缩小 / 重置 | ++ctrl+plus++ / ++ctrl+minus++ / ++ctrl+0++ |
| 切换全屏 | ++f11++ |

!!! note
    在 macOS 上，请在此表格显示 ++ctrl++ 的地方使用 ++cmd++。
