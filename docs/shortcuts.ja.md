# キーボードショートカット

よく使うショートカットの抜粋です。全一覧はコマンドパレット（++ctrl+shift+p++）に表示
されます（各コマンドにショートカットを表示）。再割り当ては
[カスタマイズ](customization.md) を参照してください。

| 操作 | ショートカット |
| --- | --- |
| コマンドパレット | ++ctrl+shift+p++ |
| タブ 新規 / 閉じる / 再度開く | ++ctrl+t++ / ++ctrl+w++ / ++ctrl+shift+t++ |
| 開く / 保存 / 名前を付けて保存 | ++ctrl+o++ / ++ctrl+s++ / ++ctrl+shift+s++ |
| 取り消し / やり直し | ++ctrl+z++ / ++ctrl+y++ |
| 切り取り / コピー / 貼り付け | ++ctrl+x++ / ++ctrl+c++ / ++ctrl+v++ |
| 検索 / 次へ / 前へ | ++ctrl+f++ / ++f3++ / ++shift+f3++ |
| 検索と置換ダイアログ | ++ctrl+r++ |
| 行へ移動 | ++ctrl+g++ |
| ファイルパネル切替 | ++ctrl+b++ |
| ペイン分割 / ペイン切替 | ++ctrl+backslash++ / ++f6++ |
| Hex表示 | ++ctrl+shift+h++ |
| ズーム 拡大 / 縮小 / リセット | ++ctrl+plus++ / ++ctrl+minus++ / ++ctrl+0++ |
| 全画面表示 | ++f11++ |

!!! note
    macOS では、表中の ++ctrl++ を ++cmd++ に読み替えてください。
